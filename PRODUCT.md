# Product

## Register

product

## Users

Chinese DIY PC builders, gaming hardware buyers, and small PC assembly shops who need to compare parts, validate compatibility, and preview a build before purchase.

## Product Purpose

This product is a China-focused 3D PC builder that combines component browsing, domestic purchase links, compatibility checks, and anchor-based 3D assembly. Success means users can choose parts with confidence, understand whether the build fits, and see the assembled machine clearly enough to inspect model placement.

## Brand Personality

Precise, technical, restrained.

## Anti-references

Avoid decorative marketing pages, oversized hero sections, toy-like configurators, and manual per-model coordinate tweaking as the core workflow. The interface should feel like a working builder tool, not a generic hardware landing page.

## Design Principles

- Keep the assembly workspace primary and legible.
- Use real part data and model metadata over visual guesswork.
- Make compatibility and placement issues inspectable.
- Prefer dense, familiar product UI patterns for repeated configuration work.
- Preserve clear separation between commerce data, compatibility data, and 3D model assets.

## Accessibility & Inclusion

Target WCAG AA contrast for core UI text, support keyboard-reachable controls, avoid relying on color alone for compatibility status, and respect reduced-motion preferences where animation is nonessential.
